# Deployment

## Vercel — Frontend

1. Import the repository into Vercel.
2. Set the project root to `client`.
3. Build command: `npm run build`.
4. Output directory: `dist`.
5. No environment variables are required for the frontend.

## Notes

The site is a static Vite/React frontend. Contact uses `mailto:himanshukaloni99@gmail.com`, so no SMTP setup is needed.
